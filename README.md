## 2. Теоретические сведения

  

### Однослойный перцептрон

Однослойный перцептрон представляет собой линейный классификатор, формирующий разделяющую гиперплоскость в пространстве признаков. Для входного вектора $\mathbf{x} \in \mathbb{R}^d$ вычисляется взвешенная сумма (логит):

$$
z = \mathbf{w}^T \mathbf{x} + b = \sum_{j=1}^{d} w_j x_j + b
$$

где $\mathbf{w} \in \mathbb{R}^d$ — вектор весов модели, $b \in \mathbb{R}$ — смещение (bias).

  

### Функция активации

Для преобразования логита $z$ в вероятность принадлежности к положительному классу $\hat{y} \in [0, 1]$ используется логистическая (сигмоидальная) функция активации:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

  

Предсказание класса $y^*$ выполняется путем порогового преобразования:

$$y^* = \begin{cases} 1, & \text{если } \sigma(z) \ge 0.5 \\ 0, & \text{если } \sigma(z) < 0.5 \end{cases}$$

  

### Функция потерь

В качестве базовой функции потерь используется бинарная кросс-энтропия (Binary Cross-Entropy), определяющая меру расхождения истинного распределения меток классов $y$ и предсказанных вероятностей $\hat{y}$:

$$L_{CE} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

  

### Алгоритм оптимизации (SGD с батчами)

Для минимизации функции потерь применяется стохастический градиентный спуск по мини-батчам (Mini-batch Stochastic Gradient Descent). На каждом шаге веса обновляются против направления градиента функции потерь, вычисленного по подвыборке размера $m$:

$$\mathbf{w} \leftarrow \mathbf{w} - \eta \frac{\partial L}{\partial \mathbf{w}}, \quad b \leftarrow b - \eta \frac{\partial L}{\partial b}$$

где $\eta$ — скорость обучения (learning rate).

Градиенты для бинарной кросс-энтропии на мини-батче имеют вид:

$$\frac{\partial L_{CE}}{\partial \mathbf{w}} = \frac{1}{m} \mathbf{X}_{batch}^T (\hat{\mathbf{y}}_{batch} - \mathbf{y}_{batch})$$

$$\frac{\partial L_{CE}}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} (\hat{y}_i - y_i)$$

## 6. Бонусное задание 2. Дополнительные функции потерь и регуляризация

  

### 6.1. Hinge Loss vs Cross-Entropy

Помимо кросс-энтропии, в класс перцептрона была интегрирована функция потерь Hinge Loss (кусочно-линейная функция потерь, используемая в методе опорных векторов SVM).

* Для Hinge Loss истинные метки преобразуются в $y \in \{-1, +1\}$.

* Функция потерь имеет вид:

  $$L_{hinge} = \frac{1}{N} \sum_{i=1}^{N} \max\left(0, 1 - y_i (\mathbf{w}^T \mathbf{x}_i + b)\right)$$

* Она штрафует не только неверные ответы, но и верные предсказания, расположенные слишком близко к границе решения (нарушающие зазор/margin).

  

Сравнение динамики обучения по двум критериям:

  

| Критерий потерь | Точность на тесте (Test Accuracy) | Финальный Train Loss |
| :--- | :--- | :--- |
| **Binary Cross-Entropy** (вероятностный) | 88.00% | 0.3309 |
| **Hinge Loss** (геометрический зазор) | **89.33%** | 0.3176 |

  

Сравнительные графики сходимости:

  

![Loss Curve CE](graphics/loss_comparison_ce.png)

![Loss Curve Hinge](graphics/loss_comparison_hinge.png)

  

**Анализ:** Hinge Loss показал более высокую точность на тесте (89.33%), так как данный критерий оптимизирует ширину разделяющего зазора (margin), максимизируя геометрическую разделимость классов.

  

### 6.2. L2-Регуляризация (Weight Decay)

L2-регуляризация добавляет к функции потерь квадратичный штраф за величину весов:

$$L_{total} = L_{base} + \alpha \|\mathbf{w}\|_2^2 = L_{base} + \alpha \sum_{j=1}^{d} w_j^2$$

где $\alpha$ — коэффициент регуляризации.

Варьирование $\alpha$ дало следующие точные числовые результаты:

  

| Параметр $\alpha$ | Точность на тесте | Норма весов $\|\mathbf{w}\|_2$ | Финальный Loss (с учетом L2) |
| :--- | :--- | :--- | :--- |
| 0.0 (Без регуляризации) | 88.00% | 3.2477 | 0.3313 |
| 0.001 | 88.00% | 3.0346 | 0.3407 |
| 0.01 | 88.67% | 2.1284 | 0.3971 |
| 0.1 | 86.00% | 0.8633 | 0.5470 |
| 1.0 (Сильный штраф) | **89.33%** | **0.1304** | 0.6682 |

  

Ниже приведены графики сходимости при $\alpha = 0.1$ и $\alpha = 1.0$:

  

![Regularization alpha = 0.1](graphics/loss_reg_01.png)

![Regularization alpha = 1.0](graphics/loss_reg_10.png)

  

**Анализ:** При увеличении $\alpha$ норма весов $\|\mathbf{w}\|_2$ стремительно падает (с 3.2477 до 0.1304). Это предотвращает переобучение и делает разделяющую гиперплоскость менее чувствительной к отдельным выбросам. Однако при излишне большом штрафе ($\alpha=0.1$ или $1.0$) вклад регуляризатора доминирует над ошибкой классификации, что приводит к росту финального loss (до 0.6682) и снижению обобщающей способности, хотя на простых данных $\alpha=1.0$ за счет сильного ограничения весов смогла достичь высокой тестовой точности (89.33%).

## 8. Бонусное задание 4. Исследование сходимости градиентного спуска (Momentum)

  

Для преодоления осцилляций обычного SGD был реализован метод Momentum (градиентный спуск с накоплением импульса):

$$\mathbf{v}_{t} = \gamma \mathbf{v}_{t-1} + \eta \nabla_{\mathbf{w}} L$$

$$\mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{v}_{t}$$

где $\gamma$ — коэффициент затухания импульса (в коде `gamma`).

  

Сравнивались обычный стохастический спуск ($\gamma = 0.0$) и Momentum с $\gamma \in \{0.5, 0.9, 0.99\}$:

  

![SGD vs Momentum](graphics/sgd_vs_momentum.png)

  

| Оптимизатор | Финальный Train Loss |
| :--- | :--- |
| **SGD** ($\gamma = 0.0$) | 0.3309 |
| **Momentum** ($\gamma = 0.5$) | 0.3309 |
| **Momentum** ($\gamma = 0.9$) | 0.3309 |
| **Momentum** ($\gamma = 0.99$) | 0.3348 |

  

**Анализ:** Momentum с $\gamma = 0.9$ существенно ускоряет темп сходимости на первых 10–20 эпохах за счет суммирования градиентов последовательных шагов в согласованном направлении. Однако при слишком большом значении $\gamma = 0.99$ импульс накапливает избыточную «кинетическую энергию», что приводит к сильным колебаниям loss и перелетам через локальные минимумы, замедляя сходимость в конце обучения.

Сетка поиска:

* Скорость обучения ($\eta$): $0.01$, $0.05$, $0.1$
